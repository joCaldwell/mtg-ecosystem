# Generated protocol SDK

Read the parent server manual and [README](README.md). Rust public DTOs/protocol
own wire definitions; no handwritten replacements for observations, responses,
tuples, quantities or counters. Mock/schema success does not qualify real hosting,
durable recovery or admitted four-player integration.

This nested package owns its exact lock and real local node_modules, outside root
workspaces. Use pinned Node and `--workspaces=false --ignore-scripts` installs;
never replace shared root dependencies. README owns build/verification commands.
The native owner supplies a compatible executable or both explicit protocol and
bootstrap schema exports with provenance; SDK commands never start Cargo or change
Rust. `MTG_SERVER_OUTPUT` is generator-test isolation, not verification's output.

`verify` generates strict declarations/standalone validators/routes, builds browser
exports, checks exhaustive responses/tuples and transport/generator tests, and
writes ignored manifests/logs. Browser proof separately runs the production ESM
under restrictive CSP with explicitly installed locked browsers. Never restore
runtime validator compilation, unsafe-eval or implicit downloads. Real-host proof
requires the independently running qualified host/private single-seat files.

Capabilities stay in private fields/Authorization, never URLs/errors/JSON logs.
Keep raw JSON/schema validation, exact numeric/cursor/body bounds, early stream
cancellation and response correlation. No automatic command retry, persistence,
policy inference or fabricated actions. A saved-state compatibility claim requires
actual native build/catalog provenance, not matching schema hashes alone.
