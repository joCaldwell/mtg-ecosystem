provenance. Never restore runtime validator compilation, unsafe-eval or implicit

and never retries commands implicitly; no persistence, journal, retry policy,
policy inference or fabricated actions. A saved-state compatibility claim requires
actual native build/catalog provenance, not matching schema hashes.
